# Challenge #44: Functions - Show Stars

## Problem

Write a function called show_stars(rows). If rows is 5, it should print the following:

## Solutions

```python
def show_stars(rows):
    for i in range(1, rows + 1):
        print("*" * i)


show_stars(5)
```
