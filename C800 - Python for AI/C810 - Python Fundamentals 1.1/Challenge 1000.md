Welcome to the Great Turtle Grand Prix, where six fearless, color-splashed champions line up on a dazzling track for the race of a lifetime!
Each turtle is unique, each lane is vibrant, and only one will claim the glory.
In this whimsical and colorful showdown, chance determines victory—every step forward is a surprise!
So sit back and cheer on your favorite racer as they sprint (well… turtle-sprint) toward the checkered finish line!

📘 Project Synopsis

This project uses Python’s turtle graphics module to create a playful race between multiple turtles.
Along a decorated racetrack, turtles move forward by random distances, simulating an unpredictable race.
The first turtle to cross the finish line is crowned the winner, followed by a celebratory announcement and fireworks.
The project emphasizes simple animation, randomness, and interactivity—making it a fun beginner-friendly way to explore Python graphics.
