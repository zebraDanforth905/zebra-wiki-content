# Challenge #09: Output - Social Media

## Problem

•
Open the file you created in Class 1 called challenge9.py.

•
Create four variables:

•
One variable to store the number 3.

•
Three variables called social1, social2, and social3 to store the names of your three favorite social media apps as strings.

•
Use a single print statement to display the message:

Top <number> social media sites are <social1>, <social2>, <social3>

•

• Replace <number> with the variable that stores 3.

• Replace <social1>, <social2>, and <social3> with your three favorite social media apps.

## Solutions

```python
three = 3

social1 = "YouTube"
social2 = "Instagram"
social3 = "TikTok"

print("My top " + str(three) + " social media sites are " + social1 + ", " + social2 + ", and " + social3)
```
