# Challenge #03: Variables - Data-Types

## Problem

Identify the following data types:

Identify the Data Type

Example

Data Type (String, integer, float, Boolean)

“Hello there”

554

-667

23.0

True

“Hi my name is John”

“23”

23.555

23

## Solutions

```python
# Challenge 3: Identify the data type of each value.
# String  -> text inside quotes
# Integer -> a whole number
# Float   -> a number with a decimal point
# Boolean -> True or False

# "Hello there"          -> String
# 554                    -> Integer
# -667                   -> Integer
# 23.0                   -> Float
# True                   -> Boolean
# "Hi my name is John"   -> String
# "23"                   -> String  (it is in quotes, so it is text)
# 23.555                 -> Float
# 23                     -> Integer

print("String, Integer, Integer, Float, Boolean, String, String, Float, Integer")
```
