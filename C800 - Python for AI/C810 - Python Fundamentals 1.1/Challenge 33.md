# Challenge #33: For Loops - Count Down

## Problem

Write a Python program to:

•
Count down numbers from 100 to 80, decreasing by 2 each time.

•
Print each number on the screen.

Hints

• Use the range() function with three arguments: start, stop, and step.

• Remember: the stop value in range() is exclusive, so adjust it accordingly.

• The step can be negative to count down.

## Solutions

```python
for number in range(100, 79, -2):
    print(number)
```
