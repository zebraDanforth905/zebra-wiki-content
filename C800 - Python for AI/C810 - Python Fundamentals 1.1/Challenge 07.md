# Challenge #07: Turtle - Rectangle

## Problem

Using turtle, draw a rectangle of dimension 800px by 1500px. Call this file Challenge7.py.

## Solutions

```python
import turtle

marty = turtle.Turtle()

marty.forward(800)
marty.left(90)
marty.forward(1500)
marty.left(90)
marty.forward(800)
marty.left(90)
marty.forward(1500)

turtle.done()
```
