# Challenge #23: Branching Logic - The Behemoth

## Problem

Write a program that checks the height of the person and determines if they are allowed on the roller coaster, The Behemoth. You are only allowed to go on The Behemoth if you are taller than 4 feet.

## Solutions

```python
height = float(input("How tall are you in feet? "))

if height > 4:
    print("You are allowed on The Behemoth!")
else:
    print("Sorry, you are too short for The Behemoth.")
```
