# Challenge #06: Turtle - Turtle Intro

## Problem

Let’s meet Turtle, a Python “robot” that can draw on your screen!
In this program, you’ll notice how we use variables—they work a bit differently here than when we store text or numbers. Don’t worry about the details just yet—simply have fun experimenting with drawing using Turtle.

Save the program above as Challenge6.py, then modify it so that it draws a square with each side measuring 200 pixels.

## Solutions

```python
import turtle

marty = turtle.Turtle()

marty.forward(100)
marty.left(90)
marty.forward(100)
marty.left(90)
marty.forward(100)
marty.left(90)
marty.forward(100)

turtle.done()
```
