# Supplemental Challenge #03: Input/Output - Fun Greeting Program

## Problem

Create a program that takes in a user’s name and then greets them with a joke.

## Solutions

```python
name = input("What is your name? ")

print("Hello, " + name + "! Here is a joke for you:")
print("Why did the " + name + " bring a ladder to school?")
print("Because they wanted to go to high school!")
```
