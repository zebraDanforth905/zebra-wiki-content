# Challenge #21: Flow Charts

## Problem

Task 1 — Read-Write Problem

Create a flowchart that:

Reads two numbers from the user, adds them, and displays the result.

Requirements:

• Start / End

• Input two numbers

• Add the numbers

• Output the sum

Task 2 — Summation Problem

Create a flowchart that:

Continuously reads numbers from the user and calculates the total sum.
Stop when the user enters 0, then display the final total.

Requirements:

• At least one loop (repeated input)

• At least one decision (check if number = 0)

• Maintain running total

• Display final sum after termination

Deliverables

Submit:

• Flowchart for Task 1

• Flowchart for Task 2

Format: PDF, PNG, or diagram link

## Solutions

```python
# Challenge 21: Flow Charts (planning exercise)

# Task 1 - Read-Write Problem: read two numbers, add them, show the result.

#   [End]

num1 = int(input("Enter the first number: "))
num2 = int(input("Enter the second number: "))
total = num1 + num2
print("The total is " + str(total))
```
