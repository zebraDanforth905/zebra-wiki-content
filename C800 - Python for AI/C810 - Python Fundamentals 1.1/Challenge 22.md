# Challenge #22: Branching Logic -  E-Input Checked

## Problem

Write a program that checks if the input string has an “e", and if it does, print "Has e". Otherwise, print “invalid input”. Remember you can use string functions that you learned before to help you.

## Solutions

```python
text = input("Enter a string: ")

if "e" in text:
    print("Has e")
else:
    print("invalid input")
```
