# Challenge #14: Casting - Birth Year

## Problem

Write a program and save it in a file called challenge15.py. In your program you need to get the age of the user, calculate the year they were born, and print that back on the screen:

The year the user was born is yyyy.

## Solutions

```python
age = int(input("How old are you? "))

currentYear = 2025
birthYear = currentYear - age

print("You were born in the year of " + str(birthYear))
```
